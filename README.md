# Our Little Universe

Интерактивное романтическое путешествие в одном самостоятельном файле — `index.html`.
Без сборки, сервера и внешних зависимостей: файл можно открыть двойным щелчком или выложить на любой статический хостинг.

## Как персонализировать

Откройте `index.html` в любом редакторе и найдите объект `CONFIG` в начале блока `<script>`. Самое важное:

| Поле | Что это |
| --- | --- |
| `herName` | имя девушки (если пусто — она введёт его сама на билете) |
| `hisName` | ваше имя: подпись в письме, финал, режим «вдвоём» |
| `date` | дата на билете (пусто — сегодняшняя) |
| `letter.paragraphs`, `letter.personal` | большое письмо и личные поля (знакомство, воспоминания, обещание) |
| `his.message` | последнее послание, которое видите только вы |
| `constellation.questions` | вопросы и варианты ответов |
| `combo` | секретная комбинация касаний |

Все остальные тексты (записки, чудеса, фразы сада, секреты, подписи кнопок) лежат там же.

## Как получить публичную ссылку

Любой статический хостинг подойдёт. Для GitHub Pages: Settings → Pages → Deploy from a branch → ветка с `index.html`, папка `/`.

## Полезно знать

- Прогресс хранится в LocalStorage браузера, поэтому путешествие можно продолжить после закрытия страницы.
- «Начать заново» — в карте маршрута, с подтверждением удержанием.
- Звук синтезируется через Web Audio и выключен, пока его не включат кнопкой.
